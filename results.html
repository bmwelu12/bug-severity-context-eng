Bug severity context-engineering — results

Does giving Claude 3 retrieved similar past bug reports (with their known severity) improve severity classification versus a no-context baseline? Real run against bmwelu12/bug-severity-context-eng, Claude Haiku 4.5, real Bugzilla bug reports.

n = 300 test rows · both conditions · 77.2% / 22.8% true class split
✓

Context helped, on balance, but with a real trade-off. Adding retrieved neighbors raised overall accuracy (75.3% → 80.3%) and raised F1 on both classes (severe F1 0.622 → 0.655, driven by a big precision gain), but it did so partly by calling "severe" less often — recall on the severe class dropped from 79.2% to 72.7%, meaning it missed more actually-severe bugs even as it cried wolf less. For a triage system, that recall drop matters more than the accuracy gain suggests. Neither run collapsed to the majority class.
